# yt-tui

Terminal YouTube Music client built with Textual, `yt-dlp`, and `mpv`.

## Current features

- full-screen TUI
- search from inside the app
- audio playback through `mpv`
- ASCII thumbnail preview
- now playing panel
- recommendation list
- keyboard controls

## Run

```bash
cd /home/avi/Code/Project/yt-tui
chmod +x yt-tui
./yt-tui
```

## Keys

- `/`: focus search
- `Esc`: move focus back to results
- `Enter`: play selected result
- `Space`: pause/resume
- `Left` / `Right`: seek 10 seconds
- `-` / `=`: volume down/up
- `n` / `p`: next/previous
- `q` or `Ctrl+C`: quit
